NEXORA AI

NEXORA AI is an interactive AI-powered smart mirror that combines computer vision, speech recognition, gesture recognition, AI image generation, and QR-based sharing into a single system.

The project is designed to let users interact with a computer naturally through voice, hand gestures, and visual input.

✨ Features
👁️ Computer Vision — Detects faces and processes the live camera feed.
🎤 Continuous Voice Commands — Allows hands-free interaction through speech.
✋ Gesture Recognition — Uses hand gestures to trigger different actions.
🎨 AI Portrait Generation — Converts captured photographs into artistic animated portraits.
📸 Photo Capture — Captures and displays the user's photograph.
🔄 Retake System — Allows users to capture another photograph.
📱 QR Sharing — Generates a unique QR code for sharing the generated portrait.
🌐 Local Sharing Server — Creates a temporary local link through which the portrait can be accessed from a phone.
🖥️ Computer Actions — Supports various voice-controlled computer operations.
